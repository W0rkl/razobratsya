# разобраться

[открыть курс](https://w0rkl.github.io/razobratsya/)

шесть коротких уроков о технологиях и бизнесе. две страницы на react и typescript: выбор темы через диски и чтение урока. сборка vite, стили tailwind и обычный css.

## запуск

из каталога проекта: `pnpm dev`.

открой `http://127.0.0.1:4173`.

## проверки и сборка

`pnpm typecheck`

`pnpm build`

обычная сборка создаёт `dist`. для github pages: `pnpm build:github`. готовые страницы, скрипты и картинки находятся в `docs`, адрес сайта начинается с `/razobratsya/`. локально проверить такую сборку: `pnpm preview:github`, затем открыть `http://127.0.0.1:4173/razobratsya/`.

github pages публикует ветку `main`, папку `/docs`. после изменений запусти typecheck и build:github, затем закоммить исходники и `docs` и отправь commit в main.

## компоненты и картинки

присланные компоненты находятся в `src/components/ui`: disc-cascade-carousel, stack-tower и sparkles-text. вращение дисков выполняется в браузере; внешний api не нужен. обложки шести тем лежат в `public/art`. белые надписи по кругу рисует svg внутри карусели.

ответы на вопросы сохраняются в памяти во время переходов между уроками. обновление страницы или возврат к дискам сбрасывает ответы. никаких внешних запросов с ответами нет. кнопка на главной останавливает постоянное вращение дисков и башню; системная настройка уменьшения движения также учитывается.
