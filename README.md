# разобраться

[открыть курс](https://w0rkl.github.io/razobratsya/)

30 уроков в 10 блоках и шести темах: продажи, вайб-кодинг, деньги, технологии, возможности и мышление. вход — короткое занятие примерно на пять минут: мысль, запись по своему проекту и один вопрос. при желании можно открыть полный урок с шестью разборами, случаем, большим заданием и двумя вопросами. длительность — ориентир, не измеренное обещание. две страницы на react и typescript: выбор темы через диски и обучение. сборка vite, стили tailwind и обычный css.

пять новых ситуаций из ресерча: удешевление инструмента, переговоры о нескольких условиях, прогнозы, стимулы и измерение пользы ии. выбираешь действие, получаешь новые данные, пересматриваешь план и сохраняешь вывод. несколько решений допустимы; обратная связь объясняет ограничения. кейсы вымышленные, исходы не предсказывают спрос или заработок. первичные ссылки и ограничения есть в самих ситуациях и sources.json.

для финансовых тем использованы отдельные идеи роберта кийосаки («богатый папа, бедный папа»); для общения и продаж — роберта чалдини («психология влияния»); для связности рекламного текста — джозефа шугермана («как создать крутой рекламный текст»). примеры, сценарии, расчёты и задания самостоятельные. полные тексты книг не воспроизводятся. книжное понимание актива отделено от бухгалтерского, а долг рассматривается с обязательствами и плохим сценарием. источники и ограничения — в уроках и sources.json.

программа: src/data/program.ts; исходные уроки: curriculum.ts; книжные уроки: book-lessons.ts; дополнительные рабочие разборы: workshops.ts. короткие занятия: briefs.ts; ситуации: scenarios.ts; отдельная схема хранения: study-progress.ts. идентификаторы, вопросы и критерии полного прохождения сохранены.

обычная ссылка learn.html?topic=sales&lesson=client открывает короткое занятие. добавление &mode=full открывает полный урок. learn.html?case=cheaper открывает ситуацию. неизвестный case показывает понятный возврат на главную. кнопка переключения режима поддерживает историю и возврат браузера. мобильное оглавление закрывается после выбора; основной путь доступен с клавиатуры.

## запуск

из каталога проекта: `pnpm dev`.

открой `http://127.0.0.1:4173`.

## проверки и сборка

`pnpm typecheck`

`pnpm test` — целостность программы, хранение полного и короткого прогресса, условия завершения, восстановление незавершённого шага и данные ситуаций. требуется node 22.6+ с поддержкой strip-types. отдельных lint и format-check команд в проекте нет.

`pnpm build`

обычная сборка создаёт `dist`. для github pages: `pnpm build:github`. готовые страницы, скрипты и картинки находятся в `docs`, адрес сайта начинается с `/razobratsya/`. локально проверить такую сборку: `pnpm preview:github`, затем открыть `http://127.0.0.1:4173/razobratsya/`.

github pages публикует ветку `main`, папку `/docs`. после изменений запусти test, typecheck и build:github, затем закоммить исходники и `docs` и отправь commit в main. отдельно пройди главный сценарий в браузере на публичном адресе; сборка не проверяет поведение.

## компоненты и картинки

присланные компоненты находятся в `src/components/ui`: disc-cascade-carousel, stack-tower и sparkles-text. вращение дисков выполняется в браузере; внешний api не нужен. обложки шести тем лежат в `public/art`. белые надписи по кругу рисует svg внутри карусели.

полные ответы и отметка практики хранятся в localStorage под прежним ключом `razobratsya-learning-v3`. полный урок завершён только после двух правильных ответов и отметки о выполнении большого задания. отметка — самопроверка, преподаватель задание не оценивает.

короткие занятия, текущий шаг и выводы по ситуациям хранятся отдельно под ключом `razobratsya-short-study-v1`. короткое занятие завершается после записи минимум в 10 символов, правильного ответа и явного нажатия «закончить». оно не завершает полный урок. ситуация требует двух решений, записи и явного завершения. запись ограничена 2000 символами; содержание автоматически не оценивается. главная возвращает к последнему незавершённому короткому занятию, в том числе в другой теме. после завершения предлагает следующий доступный шаг. серии дней и штрафы за пропуск отсутствуют.

данные переживают обновление и возврат на главную. прогресс не синхронизируется между устройствами; очистка данных сайта удаляет его. при отказе хранения курс работает в памяти и показывает предупреждение. короткие записи можно явно сохранить повторно; несохранённые изменения сохраняются в памяти при событиях другой вкладки. поздний отказ чтения не заменяет уже загруженный снимок пустыми данными. повреждённые записи игнорируются, пригодные остаются; новые действия снова пробуют сохранение. события storage обновляют открытые вкладки. абсолютно одновременная запись из разных вкладок не является транзакцией; последний снимок может победить. записи выводятся как обычный текст, никуда не отправляются; не добавляй в учебные заметки секреты клиентов.

никаких внешних запросов с ответами нет. кнопка на главной останавливает постоянное вращение дисков и башню; системная настройка уменьшения движения также учитывается. источники и границы их применения указаны в `sources.json`; ссылки проверены 8 октября 2026. суммы, сценарии, задания и вопросы составлены для курса. курс не обещает заработок и не рассчитывает индивидуальные налоговые обязательства.
